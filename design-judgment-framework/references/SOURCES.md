# Sources and research provenance

Reviewed as background sources for the *initial* developer-domain example (2026-11-24). URLs are descriptive links, not automatic evidence of the framework's effectiveness.

- Agent Skills specification: https://agentskills.io/specification — packaging conventions (`SKILL.md`, YAML frontmatter, resource folders).
- GitLab design principles: https://design.gitlab.com/about/principles/ — sophisticated simplicity and access to advanced functionality.
- GitLab research decision guidance: https://handbook.gitlab.com/handbook/upstream-studios/experience-research/when-to-conduct-ux-research/ — assess confidence alongside UX risk, with caution around competitor evidence.
- VS Code design philosophy: https://github.com/microsoft/vscode/blob/main/.github/skills/design-philosophy/SKILL.md — values → principles → UI moves, calm and focus.
- GitHub Primer design guidance: https://primer.github.io/design/guides/introduction/ — cohesion, accessibility, responsiveness, efficiency.
- Stripe API evolution retrospective: https://stripe.com/blog/payment-api-design — trade-offs between simple integrations and extensible payments APIs.

**Important:** The default weights, evidence-confidence values, candidate fit ratings and numerical thresholds are *framework-authored starting assumptions*. They are not measurements or recommendations published by the organizations above. Recalibrate with organization-specific evidence and actual validation.
